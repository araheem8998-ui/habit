# Habitflow — Daily Habit Tracker

A single-page habit tracker with weekly grid, streaks, and full persistence.

## How to Run

No build step, no npm install needed.

**Option A — Just open the file:**
```
Double-click index.html in your file explorer
```

**Option B — Local dev server (recommended):**
```bash
# Python (usually pre-installed)
python -m http.server 8080
# Then open: http://localhost:8080

# OR with Node.js
npx serve .
# Then open the URL it shows
```

That's it. No dependencies, no framework, no build tools.

## Stack

Vanilla HTML + CSS + JavaScript. Data stored in `localStorage`.
